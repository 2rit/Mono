# MONO

สมุดรายรับรายจ่ายส่วนตัวภาษาไทย ใช้แบบออฟไลน์ได้ ข้อมูลอยู่บนเครื่องนี้เท่านั้น ไม่ต้องสมัครบัญชี

Offline-first Thai personal finance app. Numbers stay on this device. No account required.

**เปิดแอป / Open:** https://2rit.github.io/Mono/

ติดตั้งลงหน้าจอหลักได้จาก Safari บน iPhone/iPad (แชร์ → Add to Home Screen) และจาก Chrome บน Android

Install from Safari on iPhone/iPad (Share → Add to Home Screen) or from Chrome on Android.
